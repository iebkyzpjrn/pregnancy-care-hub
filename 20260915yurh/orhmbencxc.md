# 咳嗽可以吃糖炒栗子吗

> 更新时间：2026-09-15 (UTC+8)

咳嗽可以吃糖炒栗子吗更新时间:2024-03-25

每到秋季栗子成熟的季节，满大街都飘着一股糖炒栗子的香味，即便是不是吃栗子的季节还是有很多的栗子买，反正一年四季都能吃到栗子的。很多人都喜欢吃栗子，但是有一些病人是不能吃炒栗子的。那么能吃炒栗子吗？

一、咳嗽能吃炒栗子吗

咳嗽是可以吃炒栗子的!但热感冒，发烧，上火的人最好不要吃!

二、咳嗽忌食

咳嗽不宜吃辛辣、油腻的食物，不宜吃太咸或太甜的食物，否则会加重上呼吸道刺激症状，引起口喝、咽干、咽部不适、咳嗽、等。

外感风寒咳嗽，咳嗽痰稀或白痰，忌吃生冷黏糯滋腻之物，如香蕉、柿子蚌肉、螃蟹等。

风热型咳嗽，黄稠，或兼有口渴、忌吃辛热黏滋补益之品，如龙眼肉、狗肉、胡椒等。其表现为流黄浊涕，咳嗽吐黄色稠粘痰，伴有汗出，咽干痛痒，口渴喜饮。 宜食辛凉清淡食品，以疏散风邪，清热解毒止咳，如菊花、茶叶、白菜、白萝卜、甜梨、甜橙等。

肺燥型咳嗽，无痰或痰少不易咳出，或鼻燥咽干， 忌吃香燥、煎炸、温热、辛辣的食物，如爆米花、炒花生、辣椒，并避开烟酒等。 宜食辛味温热性的食品，如生姜、白葱、豆豉等。

三、炒板栗的功效

在干果中，栗子提供的热能很高，充饥的同时能促进脂肪代谢。除此之外，栗子亦有较高的药用价值。祖国医学认为，栗子味甘性温，入脾、胃、肾三经，能养胃健脾、壮阳补肾、活血止血，适用引起的，所致的膝软、肢体不遂、小便频数、折伤肿痛等症。因而，肾虚者不妨多吃板栗。《本草纲目》称其有“治肾虚，腰脚，以袋盛生栗悬干，每日吃十余颗，次吃猪肾粥助之，久必强健”。

四、炒板栗的副作用

栗子的营养保健价值虽然很高，但也需要食用得法。栗子不能一次大量吃，吃多了容易胀肚。最好在两餐之间把栗子当成零食，或做在饭菜里吃，而不要饭后大量吃。这是因为栗子含淀粉较多，饭后吃容易摄入过多的热量，不利于保持体重。

五、炒栗子的做法

1. 栗子背上用刀划出缝，以利于炒时裂开

2. 栗子放到锅里，倒入开水没过栗子，放半勺盐，喜欢甜的可以加些糖。煮开后中火煮半小时。

3. 煮好后沥干，锅热倒一点油，放入栗子翻炒。6分钟后开始啪啪地裂开，不必担心会炸飞哦

4. 翻炒10分钟即可，趁热吃可太香甜了。完爆单煮的、微波炉的、烤箱的。
